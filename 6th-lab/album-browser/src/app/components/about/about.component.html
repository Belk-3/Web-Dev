About AlbumBrowser

A single-page Angular application built for Web Development Lab 6.

The App

AlbumBrowser fetches data from the JSONPlaceholder REST API and presents 100 photo albums with full CRUD operations — browse, view photos, edit titles, and delete entries.

Tech Stack

  • Angular 17+ Standalone components
  • Angular Router Multi-route SPA
  • HttpClient REST API integration
  • RxJS Observables & async pipe
  • TypeScript Typed models & services
